Personal Finance Manager
A complete React + Tailwind personal finance manager web application with budgeting, analytics, and CSV export capabilities.

Finance Manager Dashboard

🚀 Features
✅ Core Functionality
Add Income/Expense Transactions - Track all your financial activities

Transaction Management - View, edit, delete, and filter transactions

Budget Tracking - Set monthly budgets and get alerts when exceeded

Analytics Dashboard - Visual insights with charts and statistics

CSV Import/Export - Backup and restore your data

Dark Mode - Toggle between light and dark themes

Responsive Design - Works on desktop, tablet, and mobile

💳 Transaction Features
Date selection (defaults to today)

Amount input with validation

Category selection (Food, Travel, Bills, Salary, etc.)

Income/Expense type selection

Notes field for additional details

Edit and delete existing transactions

Advanced filtering by category, date range, and type

Search functionality

📊 Analytics & Insights
Overview Cards: Total Income, Total Expenses, Net Balance, Transaction Count

Expense Breakdown: Interactive pie chart by category

Monthly Trends: Line chart showing income vs expenses over time

Recent Transactions: Quick preview of latest activities

💰 Budget Management
Set monthly budget limits for each category

Visual progress bars showing spent vs budget

Alert indicators when budgets are exceeded

Budget overview with remaining amounts

🔄 Data Management
Local Storage Persistence - All data saved automatically

CSV Export - Download all transactions as spreadsheet

CSV Import - Upload and merge transaction data

Data Validation - Form validation and error handling

🎨 User Experience
Professional finance dashboard design

Smooth animations and transitions

Touch-friendly mobile interface

Accessible design with proper contrast

Loading states and user feedback

🛠️ Tech Stack
Frontend: Vanilla JavaScript (React-like patterns)

Styling: Tailwind CSS

Charts: Chart.js

CSV Processing: PapaParse

Storage: LocalStorage (Firebase-ready structure)

Icons: SVG icons

Responsive: Mobile-first design
